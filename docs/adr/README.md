# ADR

Questa cartella contiene le decisioni architetturali costose da cambiare o capaci di vincolare scelte successive.

Formato dei file: `000N-titolo-breve.md`.

Ogni ADR contiene: contesto, decisione, motivazione, conseguenze e condizioni di revisione. Dopo l'approvazione non viene riscritto: una nuova decisione lo supera mediante un nuovo ADR.
- `0005-i-pezzi-della-skill-e-il-confine-ai-deterministico.md` — i sette pezzi della skill e la linea fra AI e programma.
