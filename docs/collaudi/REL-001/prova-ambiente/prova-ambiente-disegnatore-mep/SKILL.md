# Prova dell'ambiente del Disegnatore MEP

Esegui dalla cartella di questa skill:

```bash
python3 scripts/ambiente.py
```

Riporta all'utente l'output **per intero, così com'è, in un blocco di codice**: non riassumerlo e
non commentarlo. Serve a chi sviluppa la skill vera, che lo leggerà riga per riga.

Se `python3` non esiste, prova `python scripts/ambiente.py` e dillo.
